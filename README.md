# VOICE IA RADIO - Catalogo de audio

Espejo de seguridad del catalogo de audio de VOICE IA RADIO. Aqui quedan las copias de los
archivos que la app descarga, para que el catalogo siga disponible aunque la web oficial
no lo este.

## Web oficial

**https://voice-ia-radio.vercel.app**

Esta es la fuente oficial. La app se actualiza sola desde ahi.

## Como se descargan los archivos

La app usa direcciones con la palabra \latest\, que siempre apuntan a la version mas nueva:

\\\
https://github.com/MorelDa/VOICE-IA-RADIO-AUDIO/releases/latest/download/NOMBRE_DEL_ARCHIVO
\\\

Cuando se publica una version nueva, las mismas direcciones sirven el archivo actualizado.
